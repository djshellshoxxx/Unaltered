How it works

  1. Choose a fileIts bytes remain on your device.
  2. Fingerprint locallyYour browser computes SHA-256.
  3. Request a timestampCalendars receive blinded commitments, not your file.
  4. Keep the receiptSave the standard .ots file; pending receipts need upgrading.
  5. Verify independentlyUse the original file and upgraded receipt to check Bitcoin evidence.

Archival QR certificates

The Verify page also provides printable QR receipt backup and image-based recovery. Keep the original digital .ots receipt: paper is an additional backup, not a replacement.

Independent tools and origins

Built on OpenTimestamps, created by Peter Todd, and Bitcoin. Verify with the reference command-line client. Unaltered is an independent interface.

Unaudited experimental software. A timestamp does not prove authorship or truth, and Bitcoin block time is not an exact creation time. Calendar and explorer services can observe network requests.

Cómo funciona

  1. Elige un archivoSus datos permanecen en tu dispositivo.
  2. Calcula la huella localmenteEl navegador calcula SHA-256.
  3. Solicita un sello de tiempoLos calendarios reciben compromisos ocultos, no el archivo.
  4. Guarda el reciboConserva el archivo .ots; los recibos pendientes requieren actualización.
  5. Verifica de forma independienteComprueba la evidencia de Bitcoin con el archivo original y el recibo actualizado.

Certificados QR de archivo

La página Verificar también permite imprimir copias QR del recibo y recuperarlas desde imágenes. Conserva el recibo digital .ots: el papel es una copia adicional.

Herramientas y orígenes

Basado en OpenTimestamps, creado por Peter Todd, y Bitcoin. Comprueba con el cliente de referencia. Unaltered es una interfaz independiente.

Software experimental sin auditoría independiente. Un sello no prueba autoría ni veracidad, y la hora de un bloque no es la hora exacta de creación. Los servicios externos pueden observar solicitudes de red.
