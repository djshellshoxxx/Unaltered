How it works

Stamp a file now, keep its downloaded .ots receipt, then return to upgrade and verify it once a Bitcoin block confirms the commitment.

  1. Choose a fileThe original remains on your device.
  2. Hash locallyYour browser computes its SHA-256 fingerprint.
  3. Submit commitmentCalendar servers receive timestamp commitment data, not your file.
  4. Bitcoin anchoringA calendar commits batches of timestamps to Bitcoin.
  5. Keep and upgrade receiptDownload the .ots file; a pending receipt needs later upgrading.
  6. Verify independentlyCompare the original file and upgraded receipt against Bitcoin evidence.

Step-by-step instructions

Stamp: choose your file, review optional metadata cleaning and its limitations, and create a receipt. Save the .ots download and, if cleaning was selected, the cleaned file. A pending receipt is not yet proof of Bitcoin confirmation.

Upgrade: after anchoring, open Verify and upgrade the pending .ots receipt. Keep the upgraded copy. Some calendar servers do not expose browser-readable pending responses; the reference command-line client offers an independent fallback.

Verify: supply the exact file and receipt. A valid receipt establishes that the matching bytes existed before the anchoring block, not who authored the file or whether its contents are true.

Origins and independent tools

Unaltered builds on OpenTimestamps, originally developed by Peter Todd, and on Bitcoin. Explore the OpenTimestamps command-line client (ots) and the original open-source tools. Unaltered is an independent interface, not an official OpenTimestamps service.

Privacy and beta limitations

Unaltered runs the application in your browser, with no application server, accounts or installation. The file itself is not uploaded for stamping. Timestamp commitments and verification requests contact external calendar and Bitcoin explorer services, which can observe your network address. Standard stamping does not create signing keys in the browser; it computes a file hash and uses OpenTimestamps commitments.

Experimental beta: unaudited and unsigned. Network services may be unavailable, pending receipts may require the reference client, and a timestamp is not proof of authorship, accuracy or an exact creation time. Preserve the original file and receipt; independently verify important evidence.
