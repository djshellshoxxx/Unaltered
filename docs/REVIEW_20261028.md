## Limits and remaining work

- Request fanout and timeout policies remain unchanged. Aggregate accepted trees are bounded; one parsed candidate, validation
  allocations and in-flight replies still consume bounded transient memory. Synchronous cleaner execution is not a universal
  memory/responsiveness guarantee. Original hashing and2GiB/540s/<200MiB/50ms acceptance thresholds are untouched.
- Two250000-mutation campaigns completed without findings; compact reports identify exact target bundle hashes, source state,
  Node/V8, budgets and outcomes. Coverage feedback is block-range feedback over the bundled targets/helpers/oracles, not an
  exhaustive percentage, browser decoder/pixel-equivalence proof, native sanitizer check or long multi-platform campaign.
- The test audit narrowed the old mutation property's rejection catch, made optional Python reference execution explicit and
  strengthened new mock-count/transformed-download oracles. CI still retries ordinary E2E once; a green final job alone is not
  evidence every attempt met50ms. The original memory job explicitly uses three attempts and zero retries.
- Bundled-toolkit updater/download scripts still rely on operator/upstream trust and some downloads lack pinned binary digests.
  Generated updater key enforcement, agent tool permissions and all live SDK behavior were not executed. Lower-priority static
  observations about verbose child-process pipes and cleanup-path canonicalization were not dynamically established or patched.
- R1 confirmed live app/reference round-trip, pending-calendar CORS policy, Tor/current+previous browser coverage, signing,
  independent audit/rebuild, human controls and release/account/legal requirements remain open. No backend, proxy or browser
  security bypass was introduced. No source from Claude-owned PR25 or Dependabot PR27 was merged or rewritten.
